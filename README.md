
# JavaScript 10 Questions Task

This repository contains 10 JavaScript questions covering common concepts and tricky scenarios. 
The questions include hoisting, closures, loops, type coercion, promises, destructuring, and event loop behavior.

## Questions Overview
1. **Hoisting with `var` and function scope**  
2. **For loop with `setTimeout`** (var vs let, IIFE)  
3. **Event loop & `setTimeout` with 0ms**  
4. **Array length & sparse arrays**  
5. **Weird type coercion in JavaScript**  
6. **Object comparison (`==` vs `===`)**  
7. **Function expression hoisting**  
8. **Destructuring with default values**  
9. **Promise execution order**  
10. **Nested functions & hoisting**

## How to Use
1. Open `index.js` (or your JS file containing these questions) in any code editor.
2. Run the file in the browser console or Node.js.
3. Observe the output and behavior for each question.
